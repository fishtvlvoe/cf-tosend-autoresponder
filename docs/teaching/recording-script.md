# Hokya 銷售頁 Demo 影片錄製腳本

> 目標：3~5 分鐘，一鏡到底，證明「這系統是真的」
> 錄製方式：螢幕錄影（QuickTime / OBS），語音口播照下面講，念錯直接重錄
> 前置：本機 wrangler dev 啟動，瀏覽器開乾淨的 Chrome 視窗（無書籤列、無分頁雜物）

## 流程

### 0:00–0:20 開場（停在後台儀表板）
口播：
> 「這是 Hokya，一套架在你自己帳號下面的電子報系統。我現場操作給你看，三個東西：收名單、自動寄信、排程跟進。全部繁中，零月費。」

### 0:20–1:20 收名單（著陸頁 + 訂閱）
1. 開新分頁到 `http://127.0.0.1:8787/`（訂閱著陸頁）
2. 口播：「這是你的訂閱頁，文案可以改成你自己的品牌。」
3. 在 email 欄輸入測試信箱，名字打「測試學員」，按訂閱
4. 顯示成功訊息

### 1:20–2:10 自動歡迎信（後台 + 收件匣）
1. 切回後台，點「聯絡人名單」頁籤 → 名單多一筆「測試學員」
2. 口播：「名單進來了。接著看信箱——歡迎信已經自動寄出了。」
3. 切到 Gmail，開啟剛收到的歡迎信（顯示 {{name}} 已替換成「測試學員」、底部有退訂連結）
4. 口播：「歡迎信自動發出、名字自動帶入、退訂連結自動附上——這是信箱合規的底線，Hokya 內建。」

### 2:10–3:10 排程跟進（自動跟進頁籤）
1. 回後台點「自動跟進排程」
2. 口播：「這是跟進信排程。訂閱後第 1 天、第 3 天、第 7 天自動發，內容隨你改，每一關都可以開關。」
3. 打開「關卡 02」給看主旨與內容（游標掃過即可，不用真的改）

### 3:10–3:50 手動寄信（個別發信）
1. 點「聯絡人名單」，按該筆的「個別發信」
2. 口播：「想單獨寄一封信給某個人，按這裡。」
3. 主旨已帶入，按「確認送出」，顯示成功

### 3:50–4:30 買斷與收尾（回到儀表板）
口播：
> 「這整套系統跑在你自己的 Cloudflare 帳號，買斷制，沒有月費，未來更新免費。中文介面，而且整套程式碼是你的，想改什麼丟給 AI 就能改。
> 早鳥預售三千九百八，限二十名。架不起來我們人工幫你弄到好，還不行全額退費。連結在下面。」

## 錄影要訣
- 滑鼠移動放慢 1.5 倍速的感覺，觀眾才跟得上
- 每次切換頁面停頓 1 秒再講話
- 解析度 1080p 以上，瀏覽器縮放 110%（字看得清楚）
- 錄完直接丟給我，我看過會跟你講哪裡要補
