# Change: 排程關卡瀏覽器（Sequence Step Browser）

## Why（背景）
老魚 2026-11-05 實機驗收：排程頁左側關卡列表是寫死 3 個的直排清單，關卡一多（100 封）會拉到瘋掉，無排序搜尋能力。需求：二級選單，點了才出現編輯器。

## What Changes
- 左側改動態選單：搜尋框（關卡號或主旨關鍵字）＋固定高度（lg: max-h-30rem）內部捲動＋依關卡號排序
- 「＋ 新增關卡」：取目前最大關卡號 +1，儲存時 POST /api/admin/sequences 即建（API 已支援）
- 桌面（≥1024px）：左選單右編輯器並排；手機/平板：一級列表 → 點關卡進編輯頁，「← 返回」回列表（二級導覽）
- 關卡號顯示統一兩位補零（關卡 01…關卡 100）

## Impact
- 只動 `src/adminHtml.ts`（排程頁 HTML＋JS）；API、schema 零變更

- `npm test` 42/42、`tsc --noEmit` 乾淨
