街口支付

街口支付為台灣最大的電子支付，市占率超過 50%，擁有超過 20 萬個消費通路。為金管會核准電子支付業者，並致力打造於無現金生態圈。每位顧客均完成 KYC 驗證，有效降低交易風險。

顧客使用體驗流程​

  1. 顧客在特店網站，選擇「街口支付」付款方式進行結帳；
  2. 購物頁面會跳轉到街口支付的付款頁面，會進行裝置的判斷：
    1. 如果當前裝置為 PC 瀏覽器，則展示 QR Code 頁面；
    2. 如果當前裝置為行動裝置，則展示開啟 APP 的頁面；
  3. 顧客掃描或者透過頁面打開街口支付 APP 後，會展示訂單的確認資訊；
  4. 顧客可以在街口支付 APP 選擇付款方式後，輸入付款密碼完成付款；
  5. 特店網站接收付款結果跳轉回購物訂單的結果頁面；
