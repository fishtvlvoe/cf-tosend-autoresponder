通知 Event

Webhook 是SHOPLINE Payments 透過 HTTPS 協定實現的事件通知機制，用於將特店/平台訂閱的事件資料推送到預先指定的 URL 位址。 當某個事件發生時，SHOPLINE Payments Webhook 會向該 URL 發送 HTTPS 請求，將相關事件資訊資料傳遞給特店/平台系統。

Webhook 位址設定​

請自行在 SHOPLINE Payments 後台 登入您的帳號，在後台的「設定-開發者管理」中取得 API Key / Client Key / Sign Key 資訊。其中每一個 Webhook URL 對應 一隻 Sign Key，相關 Webhook Event 請參照 Webhook 通知設定：通知[Event]
