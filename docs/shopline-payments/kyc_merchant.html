直連特店

帳戶註冊​

需先前往 SHOPLINE Payments 官網註冊，註冊成功後，SHOPLINE Payments 將為您開設帳戶。

特店登記​

要成為特店，需先提交特店資料，並得到 SHOPLINE Payments 審核透過之後才可使用。 當您透過審核，您將會收到 Mail 通知。

取得特店/平台的 API Key/ Client Key/ Sign Key​

審核透過後，特店可以在 SHOPLINE Payments 後台 登入帳號，在後台的「設定-開發者管理」中取得 API Key / Client Key / Sign Key 資訊。

確保完成付款方式的申請和設定​

  1. 登入帳戶，進入「付款方式管理」，選擇需要的付款方式，或者確保需要的串接的付款方式都已經開啟；
  2. 如果特店需要使用 ApplePay，需要補充在「設定」-「網域設定」-「管理網域」，按說明增加您的特店網站的網域（如果沒有設定，ApplePay 交易會無法進行）；
  3. 設定完成後，您可以開始進行串接；
