特店申請

SHOPLINE Payments 供兩種特店類型，平台特店、直連特店，可以根據您的業務模式選擇。

平台特店​

如果您需要為您的子特店完成付款、退款等交易，您可以申請成為 SHOPLINE Payments 的平台特店。

成為平台特店後，您還可以：

  • 代理子特店交易：使用平台自身的 API Key/ Client Key/ Sign Key 來為子特店進行付款和退款。
  • 查看子特店交易：透過平台自身的 Payment Center 查看已授權的特店的交易（即將開放）。

    • 業務場景​

    直連特店​

    如果僅為您的業務完成付款、退款交易，您可以申請直連特店。
