初始化參數說明

clientKeyString必填
通訊憑證
merchantIdString必填
SLP 特店 ID
platformIdString選填
SLP 平台 ID，平台特店必填
paymentMethodString必填參考
付款方式
currencyString必填
支援幣種，目前僅支援 TWD
amountNumber必填
付款金額，後期不再更改
elementString必填
呈現節點，若傳入字串，應為透過 document.querySelector() 取得的唯一 dom
languageString選填參考
顯示文本，預設為瀏覽器語言
countryCodeString選填
國家碼，目前僅支援 TW
envString選填參考
使用環境，預設為 production
customerTokenString選填
付款會員授權 token，用於記住顧客
installmentCountsString[] | Number[]選填
分期數，如 "3", "6", "9" 期，也可傳入 3,6,9 期，sdk 內部會轉成字串
themeObject選填
主題配置，參照 UI 介面樣式自訂
paymentInstrumentPaymentInstrument選填
付款工具參數
bindCardobject選填
綁卡場景參數
enableboolean選填
是否啟用綁定卡片功能，預設 false
protocolobject選填
綁卡協議，enable 設定為 true 時生效
switchVisibleboolean選填
是否顯示綁卡勾選框，若設定 true，顧客可自行選擇是否綁卡，若設定 false，顧客無法取消綁卡。預設 false
defaultSwitchStatusboolean選填
綁卡勾選框預設是否勾選，僅當 switchVisible 為 true 時有效。預設 true
mustAcceptboolean選填
顧客是否必須勾選綁卡勾選框，僅當 switchVisible: true 時有效，若設定 true，顧客必須勾選才能提交付款，若設定 false，不勾選也可以提交付款（即顧客可以自行選擇不綁卡付款）。預設 false
textTypeobject選填
綁卡協議文本設定
paymentAgreementboolean選填
顯示「信用卡交易協議」相關文本，預設 true。只在新增綁定卡號時展示。
subscribeAgreementboolean選填
顯示「定期付款信用卡代扣協議」相關文本，預設 true
