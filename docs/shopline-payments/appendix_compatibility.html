SDK 瀏覽器相容性

提醒
  1. 基於 SDK 內部資料統計，SDK 相容性已覆蓋到 99.94% 的常用裝置和系統 OS，剩餘裝置為少數裝置和系統 OS，如 Chrome OS、Firefox OS 等，佔比約為 0.06%。
  2. 基於 SDK 內部資料統計，SDK 相容性已覆蓋到 99.98% 的常用瀏覽器，剩餘瀏覽器為少數，如 IE、Silk 等，佔比約為 0.02%。
  3. 市場上的其他 Mobile 瀏覽器大多使用 Webkit 核心，與 Chrome 差異不大。
