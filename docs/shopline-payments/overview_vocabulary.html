重要詞彙說明

名稱說明
SHOPLINE PaymentsSHOPLINE Payments 是 SHOPLINE 品牌推出的第三方代收付服務，也可簡稱 SLP。
特店特店為特約商店的簡稱，在第三方付款中指得是與收單銀行簽訂契約的賣家。申請成為特店會有特店代號 merchantId，可用於後續串接 API 使用。為了和子特店區分開，也可稱呼為直連特店。
平台指與 SHOPLINE Payments 特別簽訂專案合約的平台賣家。若申請成為 SHOPLINE Payments 的平台將取得一組平台代號 platformId，可用於後續串接 API 使用。
子特店指授權串接功能給平台的特店。特店透過 SHOPLINE Payments 授權給平台後，平台可以代替特店進行使用和串接 API。為了和特店區分開，稱呼為子特店。
導轉式串接方式的一種，此方式透過 API 提供金流付款頁連結給特店，由特店的結帳頁進行導轉付款。
內嵌式串接方式的一種，此方式透過 SDK + API 提供金流服務給特店，讓特店在其結帳頁內嵌金流 SDK，讓顧客可以直接進行在結帳頁進行付款。此方式支援信用卡的進階服務，如綁定卡片、定期交易等。
3DS 驗證為發卡行的 3DS 驗證頁。若啟用 3DS 驗證，持卡人使用信用卡付款時，會到銀行的 3DS 驗證頁，此時需要回填銀行發送給持卡人的驗證碼才能完成 3DS 驗證。
部分發卡行開始逐漸推進 3DS 2.0 驗證，發卡行基於當下交易環境情況，直接協助完成 3DS 驗證，持卡人可以不用回填驗證碼完成 3DS 驗證。
JS SDK指 SHOPLINE Payments 的交易流程必經前端流程，部分前端交易互動功能由此 SDK 完成。亦可簡稱為 SDK。
會員指特店的顧客在 SHOPLINE Payments 註冊的會員。在系統層面上，會員會與付款工具進行關聯綁定，要求特定的付款工具只能由特定的會員使用，加強付款安全性。
付款工具指會員下關聯綁定的信用卡卡片資訊和其他付款方式資訊。
API Key指 API 金鑰，是特店或平台呼叫 SHOPLINE Payments API 的憑證。必須妥善儲存，謹防洩露。
Client Key指 Client 金鑰，是特店或平台呼叫 SDK 的憑證。必須妥善儲存，謹防洩露。
Sign Key指 Event 通知金鑰，是特店或平台接收 Event 通知的憑證。必須妥善儲存，謹防洩露。
結帳交易在導轉式串接方式下的交易形式，更和特店業務訂單邏輯相符，單筆交易可以支援多個不同付款方式付款。每次付款都會建立一筆付款交易。
付款交易在內嵌式串接方式下的交易形式，更和付款訂單邏輯相符，單筆交易僅支援一個付款方式付款。
純綁卡交易主要在非付款場景下提供顧客預先綁定信用卡操作，用於後續快捷付款及定期扣款操作
綁卡並付款交易主要在付款場景下提供顧客付款的同時，直接綁定信用卡，方便後續用於快捷付款及定期扣款操作
快捷付款交易顧客使用綁定的信用卡直接進行付款，無需輸入卡資訊
定期扣款交易顧客授權特店/平台使用信用卡在一定時間週期定時扣款，無需輸入卡資訊
