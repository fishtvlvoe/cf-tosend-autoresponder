# 好寄後台 UI/UX 驗收卡（手機版響應式）

> 定版日：2026-11-05，依老魚實機驗收意見建立。
> 參考設計：FluentCRM（assets/admin 的卡片式、icon-first 風格）。

## A. 導航

- [ ] A1 手機版（<768px）有一級選單＋漢堡選單：五個區塊（總覽／名單／廣播／排程／設定）收進漢堡抽屜，不再用擠爆的橫排頁籤
- [ ] A2 電腦版維持現有頁籤列
- [ ] A3 平板（768–1024）兩種導航都不可破版

## B. 頂部 Header

- [ ] B1 手機版改直排堆疊：標題區在上，排程狀態與操作按鈕另起一行，禁止文字直排破碎
- [ ] B2 操作按鈕（執行排程、登出）附上 SVG icon，字數精簡

## C. 卡片與內容

- [ ] C1 統計卡手機版 2×2、平板 4 欄、電腦 4 欄，樣式一致
- [ ] C2 卡片設定（陰影、圓角、間距）全站一致，參考 FluentCRM 的乾淨卡片
- [ ] C3 過長的文字說明簡化或移除，改用 SVG icon / 簡易圖示表達（如：匯出、匯入、新增、發信、設定）

## D. 表格 → 手機卡片

- [ ] D1 聯絡人名單：手機版「一筆一卡」（Email 為主標、標籤、狀態、個別發信按鈕），電腦版維持表格
- [ ] D2 投遞日誌：手機版卡片化（收件人 / 主旨 / 狀態 badge / 時間）
- [ ] D3 任何寬度下不出現欄位標題直排、內容破碎

## E. 整體

- [ ] E1 手機最小字級 14px（text-sm），text-xs 只用於輔助說明
- [ ] E2 三裝置（電腦／平板／手機）截圖對比一致，無破版
- [ ] E3 e2e-smoke 13/13 保持全綠

## 驗收方式

ADB 接 Redmi Note 8T 實機截圖 + 電腦瀏覽器截圖對比，逐項勾選。
