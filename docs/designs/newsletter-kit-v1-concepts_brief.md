# 概念報告：零月費電子報自架包（Newsletter Kit）v1

> Status: Brainstorm 完成，待老魚確認後進 Draft
> 日期：2026-11-05

## 一句話定義

給台灣自媒體人的「零月費電子報自架包」：買課程的人複製 repo、在自己 Cloudflare 帳號一鍵部署，拿到全繁中、可丟給 AI 自由改造、含「收名單 + 寄信 + 排程跟進」的電子報系統，從此不用付 ConvertKit 月費。

## Heilmeier 八大問（無黑話版）

### 1. 你想做什麼？（目標）
把現行 cf-tosend-autoresponder（已可運作）產品化成可販售的教學商品。學員拿到的不是服務，是**一套代碼 + 部署教學**，架好後完全屬於學員自己。

### 2. 痛點是什麼？（為什麼有人買）
- ConvertKit（kit.com）月費對剛起步的自媒體人是負擔（訂閱者越多越貴）。
- 英文介面不友善，台灣用語支援差。
- 想要「自己的網站、自己掌控資料」，且可用 AI（Claude/Cursor）改造。

### 3. 誰會買？（目標客群）
台灣一人自媒體創作者：講師、部落客、YouTuber、電商小賣家。會用 AI 工具但不會寫程式。一人一站，架在自有 CF 帳號。

### 4. 現在怎麼解決的？（競品對照）
| 方案 | 月費 | 中文 | 資料自主 | 可改造 |
|---|---|---|---|---|
| ConvertKit | 有，且隨名單漲價 | 差 | 否 | 否 |
| 台灣發信平台（如發信系統類） | 有 | 好 | 否 | 否 |
| 自架 Mailtrain/Mautic | 免費 | 差 | 是 | 難 |
| **本產品** | **零月費（只有 CF/ToSend 用量成本）** | **全繁中** | **是（D1 在自己帳號）** | **是（AI 友善 repo）** |

### 5. 新在哪？（差異化）
1. 全繁中 UI + 台灣用語信件範本。
2. AI 友善：每個檔案開頭中文導讀 + repo 內建 AGENTS.md，學員的 AI 助手一讀就懂系統——這是「丟給 AI 就能改」的關鍵，也是別人套件給不出的。
3. 一鍵部署：GitHub 連結 CF 授權即部署，全程不需要碰 terminal。
4. 極簡功能切線：只做收名單/寄信/排程，不塞 CRM 功能。

### 6. 風險是什麼？
| 風險 | 對策 |
|---|---|
| 學員完全不會用 CF | 課程含開戶→部署→寄出第一封信的全程影片 |
| 程式碼被盜版轉賣 | Private repo + GitHub collaborator 授權；不追技術防盜，靠教學與更新價值 |
| 學員的 ToSend Key 外洩 | Key 存 D1 並 AES 加密；外洩風險僅限其自身寄信額度，可接受 |
| CF/ToSend 改政策或漲價 | 教學中明示成本結構；程式碼可遷移 |

### 7. 要花多少錢、多少時間？
- 開發（EGM 全流程）：約 6~8 個工作天對話輪次。
- 學員端成本：CF 免費額度內（D1/Workers 免費額度對百人名單綽綽有餘）+ ToSend 用量計費。

### 8. 成功的樣子？（驗收）
「零基礎學員」從買課程到寄出第一封自動信：< 1 小時完成，全程無卡關。以此為 e2e 驗收劇本。

## v1 功能切線（已與老魚確認）

**做：**
- 設定精靈（開箱第一次進後台引導）+ 設定頁：ToSend Key、寄件人名稱/信箱、網域、著陸頁文案、登入密碼
- 訂閱著陸頁（可自訂標題/文案）
- 名單管理：手動新增、CSV 匯入/匯出、搜尋、退訂狀態
- 標籤：貼標籤、依標籤篩選、寄信時選標籤受眾
- 歡迎信 + 3 關跟進信排程（可編輯、可開關）
- 手動單發 / 測試信 / 依標籤群發
- 發信紀錄、合規一鍵退訂（RFC 8058 精神）
- 全繁中 UI、AI 友善 repo（檔案導讀 + AGENTS.md）
- GitHub 連結 CF 一鍵部署（GitHub Actions workflow + 建 D1 + migration 自動化）

**砍（v1 不做）：**
- 多使用者 / 權限分層
- Campaigns 進階版（排定日期群發、A/B 測試）
- 開信率/點擊率追蹤（ToSend 有無 webhook 回傳待查，先不做）
- 銷售系統（收款 + 序號 + GitHub 邀請）→ 第二期

## 技術基線（沿用現行 repo，不重寫）

- 單一 Cloudflare Worker + D1（SQLite），TypeScript，Vitest
- ToSend API 寄信；Drip 排程用 CF Cron Trigger
- 設定存 D1 `settings` 表（ToSend Key 欄位 AES-256-GCM 加密）
- 部署：repo 內建 GitHub Actions（push 觸發 wrangler deploy + d1 migrations apply）

## 已定案決策（老魚 2026-11-05 確認）

1. **商品 repo**：全新乾淨 private repo，不含任何真實名單/測試資料/敏感歷史。
2. **定價模式**：**買斷制**（付一次，永久取得 repo 與未來更新；不做年費踢人機制）。GitHub 邀請機器人只做單向授權。
3. **產品名**：**好好寄**（英文 slug：`haoji`；repo 名：`haoji-newsletter`；課程標題：《好好寄：零月費電子報自架課》）。
4. **網域**：本期不使用自有網域（學員各自綁自己的）。銷售站（第二期）屆時再從 aiver.me / buygo.me / fishot.com 等選子網域。
